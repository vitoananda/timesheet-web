# Place Your Logo File Here

To use your exact official logo image file:
1. Copy your logo image into this folder (`public/images/`)
2. Name it **`logo.png`** (or `.jpg`, `.svg`)

The application is programmed to:
- Automatically display `public/images/logo.png` if present.
- Seamlessly fallback to the built-in crisp vector Metrodata SVG logo if the file hasn't been placed yet.
